# Leocraft – Sprite Assets

## Source
These sprites were generated as custom CC0 SVG artwork for the Leocraft project.

## Animals (circus world)
Flat-design SVG sprites: elephant, giraffe, monkey, zebra, bear, hippo, tiger, panda

## Food (supermarket world)
Flat-design SVG sprites: apple, banana, pear, orange, strawberry, carrot, cucumber, tomato, corn, broccoli, lemon, pepper

## Format
- 128x128 SVG viewbox
- Transparent background
- Flat design, child-friendly
- Loaded by Phaser as SVG textures at runtime
