# Worlds Art Direction

## Sdílené vizuální principy

- **Animátor:** Leo (🦁) je průvodce ve všech třech světech. Vždy vlevo na jevišti/pultu.
- **Konzistence:** Stejný font, stejná typografie nadpisů, stejné pilule v HUD.
- **Odlišnost:** Každý svět má vlastní barevnou náladu, osvětlení a dekorace.
- **Premium look:** Gradient stropy, layered shadows, ambient animace světel.

---

## 🎪 Cirkus (Phase 1)

**Mood:** Show, magie, radost, spektákl.

| Prvek | Popis |
|---|---|
| Strop | Deep crimson gradient (0x4A0808 → 0xA01820) + diagonální krémové pruhy |
| Stěny | Warm cream + červené záclony na krajích + triangulová girlanda |
| Podlaha | Warm reddish wood + kruhové ohnisko (ring) |
| Světla | Řetěz barevných karnevalových žárovek (červená, žlutá, modrá, zelená) |
| Pás | Dark crimson frame + deep red surface (velvet feel) |
| Přízvuk | Gold (0xFFD700) |
| Badge bubliny | Crimson red (0xC41E3A) |

**Dekorace:**
- Circus poster panely na pravé stěně (3 barevné obdélníky)
- Barevná girlanda (bunting) podél stropu
- Červené divadelní záclony na bocích

## 🛒 Supermarket (Phase 2)

**Mood:** Čerstvost, čistota, retail, hravá zelenina.

| Prvek | Popis |
|---|---|
| Strop | Commercial blue gradient (0x2255A0 → 0xC8E0FF) |
| Stěny | Clean white-blue + organize shelf se zeleninou |
| Podlaha | Light gray tiles |
| Světla | Fluorescent tube strips (studená bílá, horizontální) |
| Pás | Standard industrial dark (stejné jako original) |
| Přízvuk | Fresh teal (0x2EC4B6) |
| Badge bubliny | Green (0x20A040) |

**Dekorace:**
- Produce display case s policemi a barevnou zeleninou/ovocem
- Zelený "ČERSTVÉ" banner nad police

## 🏠 Rodinný dům (Phase 3)

**Mood:** Teplo, bezpečí, útulnost, domov.

| Prvek | Popis |
|---|---|
